# Python: шпаргалка по типам, функциям и полезным приёмам

Для подготовки к собеседованию на стажировку. Версия справочника — Python 3.14; особенности новых версий отмечены. Не нужно заучивать всё: сначала разделы 1–8 и рецепты из раздела 12.

Здесь перечислены все публичные методы основных встроенных типов данных: str, list, tuple, dict, set, frozenset, int, float, complex, bool, bytes, bytearray, memoryview, range. Служебные методы с двумя подчёркиваниями разобраны отдельно на основных примерах. Методы объектов из модулей стандартной библиотеки (datetime, pathlib и т. д.) — отдельные справочники; это не методы встроенных типов. Исключения и их методы здесь не каталогизируются.

Это справочник, а не список уже пройденных тем. Если конструкция встречается здесь впервые, перед упражнением её нужно отдельно разобрать.

## 1. Метод, функция, атрибут и оператор

| Что | Пример | Как читать |
|---|---|---|
| Встроенная функция | `len(items)` | Передаём объект в функцию |
| Метод | `items.append(3)` | Вызываем действие у объекта |
| Атрибут | `task.done` | Читаем данные объекта; скобок нет |
| Оператор | `a + b`, `x in items` | Операция с объектами |
| Конструктор типа | `list(values)` | Создаём объект / преобразуем данные |

`len` — функция, а не метод списка. Запись `items.len()` для обычного списка неверна.

В таблицах `x`, `s`, `d`, `items` — условные имена объектов. Аргументы со значениями вроде `reverse=True` передаются по имени. Вызов метода не означает, что исходный объект обязательно изменится.

## 2. Какой тип выбрать

| Тип | Пример | Меняется на месте? | Назначение |
|---|---|---|---|
| `list` | `[1, 2, 2]` | Да | Последовательность, дубликаты допустимы |
| `tuple` | `(1, 2)` | Нет | Фиксированный набор позиций |
| `str` | `"Python"` | Нет | Текст Unicode |
| `dict` | `{"id": 1}` | Да | Поиск значения по ключу |
| `set` | `{1, 2}` | Да | Уникальность, проверка наличия, операции множеств |
| `frozenset` | `frozenset({1, 2})` | Нет | Неизменяемое множество |
| `range` | `range(5)` | Нет | Арифметическая последовательность целых без хранения списка |
| `int`, `float`, `complex`, `bool` | `1`, `1.5`, `2j`, `True` | Нет | Числа и логические значения |
| `bytes` | `b"abc"` | Нет | Байты |
| `bytearray` | `bytearray(b"abc")` | Да | Изменяемые байты |
| `memoryview` | `memoryview(b"abc")` | Зависит от буфера | Представление существующего буфера |
| `NoneType` | `None` | Нет | Отсутствие значения; специальных публичных методов нет |

Ключи словаря и элементы множества должны быть хешируемыми. Строки и числа подходят, списки и словари — нет. Кортеж хешируем, только если хешируемы все его элементы. Неизменяемость внешнего контейнера не делает его содержимое автоматически хешируемым.

`{}` — пустой словарь. Пустое множество — `set()`. Кортеж из одного элемента — `(1,)`.

## 3. list — все публичные методы

| Метод | Действие | Результат вызова |
|---|---|---|
| `a.append(x)` | Добавить один объект в конец | `None` |
| `a.extend(values)` | Добавить все элементы из перебираемого объекта | `None` |
| `a.insert(i, x)` | Вставить перед позицией `i` | `None` |
| `a.remove(x)` | Удалить первое равное `x` значение | `None`; нет значения → `ValueError` |
| `a.pop(i)` | Удалить и вернуть элемент; без `i` — последний | Удалённый элемент; неверный индекс → `IndexError` |
| `a.clear()` | Удалить все элементы | `None` |
| `a.index(x)` | Индекс первого совпадения | Число; нет значения → `ValueError` |
| `a.count(x)` | Число совпадений | Число |
| `a.sort(key=None, reverse=False)` | Отсортировать существующий список | `None` |
| `a.reverse()` | Развернуть существующий список | `None` |
| `a.copy()` | Создать поверхностную копию | Новый список |

У `index` можно ограничить диапазон: `a.index(x, start, stop)`; правая граница не включается.

```python
a = [1, 2]
a.append([3, 4])   # a == [1, 2, [3, 4]]

b = [1, 2]
b.extend([3, 4])   # b == [1, 2, 3, 4]
```

Не пиши `a = a.sort()` или `a = a.append(3)`: переменная станет `None`.

Операции вне методов: `a[i]`, `a[start:stop:step]`, `a[i] = x`, `del a[i]`, `x in a`, `a + b`, `a * n`, `len(a)`.

## 4. tuple и range

| Тип и метод | Действие |
|---|---|
| `t.count(x)` | Сколько раз встречается `x` |
| `t.index(x)` | Индекс первого совпадения; иначе `ValueError` |
| `r.count(x)` | Число вхождений в `range` |
| `r.index(x)` | Индекс значения в `range`; иначе `ValueError` |

Это все публичные методы этих двух типов. У `range` есть атрибуты `start`, `stop`, `step`.

```python
list(range(2, 8, 2))   # [2, 4, 6]; stop=8 не включается
list(range(3, 0, -1))  # [3, 2, 1]
```

Кортеж нельзя изменить по позиции, но вложенный изменяемый объект менять можно:

```python
t = ([1], 2)
t[0].append(3)  # t == ([1, 3], 2)
```

## 5. str — все публичные методы

Строковые методы возвращают результат, не изменяя исходную строку. В примерах `s` — строка.

### Регистр и пробелы

| Метод | Действие / пример |
|---|---|
| `s.lower()` | В нижний регистр: `"SQL" → "sql"` |
| `s.upper()` | В верхний регистр |
| `s.casefold()` | Нормализация регистра для сравнения: `"ß" → "ss"` |
| `s.capitalize()` | Первый символ в заглавный регистр, остальные — в нижний |
| `s.title()` | Регистр для начала слов; не лингвистический редактор заголовков |
| `s.swapcase()` | Поменять регистр символов |
| `s.strip()` | Удалить пробельные символы с обоих краёв |
| `s.lstrip()` | Удалить пробельные символы слева |
| `s.rstrip()` | Удалить пробельные символы справа |
| `s.removeprefix(prefix)` | Удалить точный префикс, если есть |
| `s.removesuffix(suffix)` | Удалить точный суффикс, если есть |

`strip(chars)` удаляет любые символы из набора `chars` с краёв, а не точную подстроку:

```python
"abPythonba".strip("ab")          # 'Python'
"report.txt".removesuffix(".txt") # 'report'
```

### Поиск, замена, разделение и сборка

| Метод | Действие |
|---|---|
| `s.find(sub)` | Индекс первого вхождения; если нет — `-1` |
| `s.rfind(sub)` | Индекс последнего вхождения; если нет — `-1` |
| `s.index(sub)` | Как `find`, но при отсутствии — `ValueError` |
| `s.rindex(sub)` | Как `rfind`, но при отсутствии — `ValueError` |
| `s.count(sub)` | Число неперекрывающихся вхождений |
| `s.startswith(prefix)` | Проверить начало; можно передать кортеж префиксов |
| `s.endswith(suffix)` | Проверить конец; можно передать кортеж суффиксов |
| `s.replace(old, new, count)` | Заменить вхождения; `count` необязателен |
| `s.split(sep=None, maxsplit=-1)` | Разделить слева, вернуть список |
| `s.rsplit(sep=None, maxsplit=-1)` | Разделять справа; полезно при ограничении `maxsplit` |
| `s.splitlines(keepends=False)` | Разбить по границам строк |
| `sep.join(strings)` | Соединить строки разделителем `sep` |
| `s.partition(sep)` | Кортеж `(до, разделитель, после)` по первому совпадению |
| `s.rpartition(sep)` | То же по последнему совпадению |

Поисковые методы `find`, `rfind`, `index`, `rindex`, `count`, а также `startswith`, `endswith` допускают границы `start`, `end`.

```python
" a   b ".split()       # ['a', 'b']; пробелы группируются, пустые края убираются
"a,,b".split(",")       # ['a', '', 'b']; явный разделитель сохраняет пустые части
", ".join(["SQL", "Python"])  # 'SQL, Python'
"id=42".partition("=")  # ('id', '=', '42')
"abc".partition("=")    # ('abc', '', '')
"abc".rpartition("=")   # ('', '', 'abc')
```

### Проверки — возвращают bool

| Метод | Что проверяет |
|---|---|
| `s.isalpha()` | Непустая строка только из букв |
| `s.isdecimal()` | Непустая строка из десятичных цифр Unicode |
| `s.isdigit()` | Цифры; включает больше символов, чем `isdecimal`, например `²` |
| `s.isnumeric()` | Числовые символы; ещё шире, например `½` |
| `s.isalnum()` | Непустая строка из букв и числовых символов |
| `s.isspace()` | Непустая строка только из пробельных символов |
| `s.islower()` | Есть регистровые символы, и все они в нижнем регистре |
| `s.isupper()` | Есть регистровые символы, и все они в верхнем регистре |
| `s.istitle()` | Соответствие правилам title case Python |
| `s.isascii()` | Только ASCII; для пустой строки тоже `True` |
| `s.isprintable()` | Все символы печатные; для пустой строки тоже `True` |
| `s.isidentifier()` | Допустимая форма имени; ключевые слова не исключаются |

`"-3".isdigit()` — `False`. Для преобразования пользовательского ввода в число надёжнее `int(text)` с обработкой `ValueError`. `"class".isidentifier()` — `True`, но использовать `class` как имя переменной нельзя; ключевые слова проверяет `keyword.iskeyword()`.

### Форматирование, кодирование, преобразования

| Метод | Действие / пример |
|---|---|
| `s.center(width, fillchar=" ")` | Дополнить с двух сторон |
| `s.ljust(width, fillchar=" ")` | Дополнить справа |
| `s.rjust(width, fillchar=" ")` | Дополнить слева |
| `s.zfill(width)` | Дополнить нулями, учитывая знак: `"-7".zfill(4) → '-007'` |
| `s.expandtabs(tabsize=8)` | Табуляции заменить пробелами до позиций табуляции |
| `s.format(*args, **kwargs)` | Подставить значения: `"Привет, {}".format("Анна")` |
| `s.format_map(mapping)` | Подстановка из отображения: `"{name}".format_map({"name": "Анна"})` |
| `str.maketrans(...)` | Подготовить таблицу замен для `translate` |
| `s.translate(table)` | Заменить/удалить символы по таблице |
| `s.encode(encoding="utf-8", errors="strict")` | Строку превратить в `bytes` |

```python
table = str.maketrans("аб", "ab")
"абба".translate(table)  # 'abba'
"кот".encode("utf-8").decode("utf-8")  # 'кот'
```

Для обычной подстановки удобны f-строки. `f` перед кавычками включает вычисление выражений внутри `{}`:

```python
name = "Степан"
score = 8.5
text = f"{name}: {score:.2f}"  # 'Степан: 8.50'; .2f — два знака после точки
```

## 6. dict — все публичные методы

| Метод | Действие | Если ключа нет |
|---|---|---|
| `d.get(key, default=None)` | Получить значение, не добавляя ключ | Вернёт `default` |
| `d.keys()` | Представление ключей | — |
| `d.values()` | Представление значений | — |
| `d.items()` | Представление пар `(ключ, значение)` | — |
| `d.update(other)` | Добавить/перезаписать пары; вернуть `None` | Добавит ключ |
| `d.setdefault(key, default=None)` | Вернуть значение; если ключа нет, записать `default` | Добавит ключ |
| `d.pop(key, default)` | Удалить ключ и вернуть значение | `default`; без него `KeyError` |
| `d.popitem()` | Удалить и вернуть последнюю добавленную пару | Для пустого словаря `KeyError` |
| `d.clear()` | Удалить всё; вернуть `None` | — |
| `d.copy()` | Поверхностная копия | — |
| `dict.fromkeys(keys, value=None)` | Новый словарь с общим значением для всех ключей | — |

`d[key]` при отсутствии ключа вызывает `KeyError`. `key in d` проверяет ключи, не значения. `keys()`, `values()`, `items()` — не снимки-списки: отражают последующие изменения словаря. Для снимка — `list(d.items())`.

```python
d = {"a": 1, "b": 2}
for key, value in d.items():
    print(key, value)
```

`key, value` — распаковка пары: первый элемент попадёт в `key`, второй в `value`.

Ловушка `fromkeys`:

```python
bad = dict.fromkeys(["a", "b"], [])
bad["a"].append(1)  # bad == {'a': [1], 'b': [1]} — список общий

good = {key: [] for key in ["a", "b"]}  # отдельный список на каждый ключ
```

Объединение словарей: `a | b` создаёт новый словарь, при совпадении ключей выигрывает `b`. `a |= b` обновляет `a`. Эти операции доступны с Python 3.9. Словарь сохраняет порядок вставки; это гарантия языка с 3.7. Перезапись значения существующего ключа его не перемещает; удаление и повторная вставка перемещают в конец.

## 7. set и frozenset — все публичные методы

| Метод | Действие |
|---|---|
| `s.add(x)` | Добавить элемент |
| `s.update(values)` | Добавить элементы из одного или нескольких итерируемых объектов |
| `s.remove(x)` | Удалить; отсутствие → `KeyError` |
| `s.discard(x)` | Удалить, если есть; отсутствие допустимо |
| `s.pop()` | Удалить и вернуть произвольный элемент; пустое → `KeyError` |
| `s.clear()` | Удалить все элементы |
| `s.copy()` | Поверхностная копия |
| `s.union(other)` | Объединение: элементы хотя бы одного множества |
| `s.intersection(other)` | Пересечение: общие элементы |
| `s.difference(other)` | Элементы `s`, отсутствующие в другом |
| `s.symmetric_difference(other)` | Элементы только одного из двух множеств |
| `s.difference_update(other)` | Разность с изменением `s` |
| `s.intersection_update(other)` | Пересечение с изменением `s` |
| `s.symmetric_difference_update(other)` | Симметрическая разность с изменением `s` |
| `s.issubset(other)` | Все элементы `s` есть в другом? |
| `s.issuperset(other)` | `s` содержит все элементы другого? |
| `s.isdisjoint(other)` | Нет общих элементов? |

Изменяющие методы возвращают `None`, кроме `pop`, который возвращает элемент. `frozenset` поддерживает только: `copy`, `union`, `intersection`, `difference`, `symmetric_difference`, `issubset`, `issuperset`, `isdisjoint`.

```python
a = {1, 2, 3}
b = {3, 4}

a | b  # {1, 2, 3, 4} — union
a & b  # {3} — intersection
a - b  # {1, 2} — difference
a ^ b  # {1, 2, 4} — symmetric_difference
a <= b # False — подмножество; < означает строгое подмножество
a >= b # False — надмножество; > означает строгое надмножество
```

Порядок множества не гарантируется. `pop()` не обещает первый/последний/случайный элемент. Для упорядоченного вывода используй `sorted(s)` — получится список.

## 8. Встроенные функции: самые нужные

Встроенные функции доступны без `import`. Некоторые имена в этом списке являются типами, которые тоже можно вызывать.

| Вызов | Что делает | Пример |
|---|---|---|
| `len(x)` | Число элементов | `len({"a": 1}) → 1` |
| `print(...)` | Вывод; возвращает `None` | `print("a", "b", sep=", ")` |
| `input(prompt)` | Прочитать строку | `age = int(input("Возраст: "))` |
| `type(x)` | Получить тип | `type([]) is list` |
| `isinstance(x, T)` | Проверка типа с учётом наследования | `isinstance(3, int)` |
| `int`, `float`, `complex` | Преобразование/создание чисел | `int("10")`, `int("ff", 16)` |
| `str`, `bool` | Строка, логическое значение | `str(42)`, `bool([]) → False` |
| `list`, `tuple`, `set`, `frozenset`, `dict` | Создание контейнеров | `list("ab") → ['a', 'b']` |
| `range(start, stop, step)` | Последовательность целых | `range(5)` — от 0 до 4 |
| `sum(values, start=0)` | Сумма | `sum([2, 3]) → 5` |
| `min`, `max` | Минимум/максимум; поддерживают `key` | `min([3, 1]) → 1` |
| `abs(x)` | Модуль числа | `abs(-3) → 3` |
| `round(x, ndigits)` | Округление | `round(3.14159, 2) → 3.14` |
| `pow(x, y)` | Степень; третий аргумент — модуль | `pow(2, 3) → 8` |
| `divmod(a, b)` | Пара: целочисленное частное и остаток | `divmod(17, 5) → (3, 2)` |
| `sorted(values, key=None, reverse=False)` | Новый отсортированный список | `sorted([3, 1]) → [1, 3]` |
| `reversed(values)` | Обратный итератор | `list(reversed([1, 2])) → [2, 1]` |
| `enumerate(values, start=0)` | Итерация по парам индекс/элемент | `list(enumerate(['a'], 1)) → [(1, 'a')]` |
| `zip(a, b)` | Пары из нескольких источников | `list(zip([1, 2], ['a', 'b']))` |
| `all(values)` | Все элементы истинны? | `all([True, True]) → True` |
| `any(values)` | Есть хотя бы один истинный? | `any([False, True]) → True` |
| `map(func, values)` | Применять функцию к элементам | `list(map(int, ['1', '2'])) → [1, 2]` |
| `filter(func, values)` | Оставлять элементы с истинной проверкой | `list(filter(None, [0, 1, '', 'x'])) → [1, 'x']` |
| `iter(x)` | Получить итератор | `it = iter([1, 2])` |
| `next(it, default)` | Следующий элемент | `next(iter([]), None) → None` |
| `open(path, mode, encoding=...)` | Открыть файл | `open('notes.txt', 'r', encoding='utf-8')` |
| `help(x)` | Справка | `help(str.split)` |
| `dir(x)` | Имена доступных атрибутов | `dir([])` |

`min([], default=None)` допустим; `default` используется в форме с одним итерируемым аргументом. Без него пустая последовательность вызывает `ValueError`. `sum` не предназначен для склейки строк — используй `join`.

`zip` обычно останавливается на самом коротком источнике. `zip(a, b, strict=True)` обнаруживает несовпадение длин при переборе (Python 3.10+). `map` тоже поддерживает `strict=True`, но только с Python 3.14 и при нескольких источниках.

## 9. Остальные встроенные функции и вызываемые типы

### Представление, числа, байты

| Имя | Назначение |
|---|---|
| `repr(x)` | Представление для диагностики: строки с кавычками/экранированием |
| `ascii(x)` | Как `repr`, с экранированием не-ASCII |
| `format(x, spec)` | Форматирование: `format(3.5, '.2f') → '3.50'` |

## 12. Практические приёмы с объяснениями

### Сортировка: сначала понять key и lambda

`key` — функция, которая получает элемент и возвращает значение для сравнения при сортировке. Она не преобразует сами элементы результата.

```python
words = ["python", "go", "java"]
sorted(words, key=len)  # ['go', 'java', 'python']; сравниваем длины
```

`lambda` — короткая функция из одного выражения. Следующие определения делают одно и то же:

```python
def get_score(pair):
    return pair[1]

get_score_short = lambda pair: pair[1]
```

В паре `('Анна', 80)` индекс `0` — имя, индекс `1` — балл. Обычная `def` подходит для `key` точно так же, как `lambda`.

### Как отсортировать словарь и зачем

```python
scores = {"Борис": 70, "Анна": 90, "Вера": 80}

# 1. Только ключи по возрастанию — результат list, а не dict
names = sorted(scores)
# ['Анна', 'Борис', 'Вера']

# 2. Новый словарь с порядком вставки по ключу
by_name = dict(sorted(scores.items()))
# {'Анна': 90, 'Борис': 70, 'Вера': 80}

# 3. Пары по значению, от большего к меньшему
pairs = sorted(scores.items(), key=lambda pair: pair[1], reverse=True)
# [('Анна', 90), ('Вера', 80), ('Борис', 70)]

# 4. Если нужен именно словарь с таким порядком
by_score = dict(pairs)

# 5. Значение по убыванию, при равенстве — имя по возрастанию
ranked = sorted(scores.items(), key=lambda pair: (-pair[1], pair[0]))
```

Зачем: рейтинг, упорядоченный отчёт, первые N записей, воспроизводимый вывод. Для простого поиска `scores['Анна']` сортировка не нужна и не делает поиск быстрее. Часто лучше оставить результат списком пар: он прямо выражает последовательность рейтинга.

У словаря нет `.sort()`. Новый словарь хранит получившийся порядок вставки, но не поддерживает автоматическую сортировку: добавленная позже пара попадёт в конец. Обычное равенство словарей не учитывает порядок: `{'a': 1, 'b': 2} == {'b': 2, 'a': 1}` — `True`.

### Сортировка списка словарей

```python
users = [
    {"name": "Борис", "age": 25},
    {"name": "Анна", "age": 20},
    {"name": "Вера", "age": 20},
]

ordered = sorted(users, key=lambda user: (user["age"], user["name"]))
# Сначала age, при равенстве name: Анна, Вера, Борис
```

Кортежи сравниваются последовательно по позициям. Сортировка стабильная: при равных ключах исходный взаимный порядок элементов сохраняется. Несравнимые ключи, например `None` и число, требуют отдельного правила.

### list.sort против sorted

```python
numbers = [3, 1, 2]
ordered = sorted(numbers)  # новый список; numbers остаётся прежним
numbers.sort()            # меняет numbers; возвращает None
```

### Убрать дубликаты

```python
values = [3, 1, 3, 2, 1]
unique = list(set(values))           # порядок не гарантирован
unique_ordered = list(dict.fromkeys(values))  # [3, 1, 2]
```

Оба варианта требуют хешируемых элементов. Для списка словарей нужно отдельно выбрать критерий уникальности, например `user_id`.

### Comprehension — создание контейнера по правилу

```python
numbers = [1, 2, 3, 4]
squares = [n * n for n in numbers]           # [1, 4, 9, 16]
evens = [n for n in numbers if n % 2 == 0]   # [2, 4]
squares_by_n = {n: n * n for n in numbers}   # {1: 1, 2: 4, 3: 9, 4: 16}
remainders = {n % 2 for n in numbers}        # {0, 1}
```

Читать так: «возьми выражение слева для каждого элемента из источника, если выполнено условие». Квадратные скобки создают список, фигурные с `ключ: значение` — словарь, фигурные с одним выражением — множество.

### Группировка и подсчёт

```python
words = ["sql", "python", "sql"]
counts = {}
for word in words:
    counts[word] = counts.get(word, 0) + 1

orders = [
    {"user_id": 1, "amount": 100},
    {"user_id": 1, "amount": 50},
    {"user_id": 2, "amount": 80},
]
groups = {}
for order in orders:
    groups.setdefault(order["user_id"], []).append(order)
```

`setdefault` вернёт существующий список группы или запишет новый. Более специализированные инструменты стандартной библиотеки — `collections.Counter` и `collections.defaultdict`; они требуют импорта.

### Распаковка и звёздочка

```python
name, score = ("Анна", 90)     # распаковка двух элементов
first, *middle, last = [1, 2, 3, 4]  # middle == [2, 3]

def add(a, b):
    return a + b

pair = (2, 3)
result = add(*pair)            # как add(2, 3)
params = {"a": 2, "b": 3}
result = add(**params)         # как add(a=2, b=3)
```

В объявлении `def f(*args, **kwargs)` звёздочки собирают позиционные аргументы в кортеж `args`, именованные — в словарь `kwargs`. В вызове они, наоборот, распаковывают данные. Имена `args` и `kwargs` — соглашение, а не ключевые слова.

### Срезы

```python
values = [0, 1, 2, 3, 4]
values[1:4]   # [1, 2, 3]; правая граница не включена
values[:2]    # [0, 1]
values[2:]    # [2, 3, 4]
values[::2]   # [0, 2, 4]
values[::-1]  # [4, 3, 2, 1, 0]
values[-1]   # 4; на пустом списке IndexError
```

Для списка `values[:]` — поверхностная копия. Срез за границами обычно допустим; одиночный недопустимый индекс — ошибка. Шаг среза не может быть нулевым.

### Итератор расходуется

```python
it = iter([10, 20])
next(it)       # 10
list(it)       # [20]
list(it)       # [] — уже исчерпан
next(it, None) # None — значение по умолчанию
```

Без значения по умолчанию `next` на исчерпанном итераторе вызывает `StopIteration`. `map`, `filter`, `zip`, `enumerate`, `reversed` возвращают итераторы, а не готовые списки. Обычный список можно перебирать повторно: каждый `iter(list)` создаёт новый итератор.

### Чтение файла

```python
with open("notes.txt", "r", encoding="utf-8") as file:
    text = file.read()
```

`with` обеспечивает закрытие файла при выходе из блока, в том числе при исключении. Режимы: `r` — чтение, `w` — запись с очисткой существующего файла, `a` — добавление в конец, `b` — двоичный режим. В бинарном режиме `encoding` не передают.

## 13. Частые ловушки

### Изменение, копия и новое присваивание

```python
a = [1, 2]
b = a          # тот же список
c = a.copy()   # новый внешний список
b += [3]       # изменяет общий список a/b
b = b + [4]    # создаёт новый список и перепривязывает только b
```

Поведение `+=` зависит от типа: для списка это изменение на месте, для строки — новое значение. Поверхностная копия не копирует вложенные объекты; для глубокой копии часто подходит `copy.deepcopy`, но её необходимость зависит от задачи.

### Общие вложенные списки

```python
bad = [[0] * 3] * 2
bad[0][0] = 1  # bad == [[1, 0, 0], [1, 0, 0]]

good = [[0] * 3 for _ in range(2)]  # независимые строки
```

Здесь `_` — обычное имя переменной по соглашению: значение индекса нам не нужно.

### Изменяемый аргумент по умолчанию

```python
def add_skill(skill, skills=None):
    if skills is None:
        skills = []
    skills.append(skill)
    return skills
```

При `skills=[]` в объявлении один список использовался бы повторно между вызовами без этого аргумента. `if not skills` не равно `if skills is None`: первый вариант также считает пустой переданный список ложным.

### Пустота, None и сравнение

```python
bool([])        # False
bool({})        # False
bool(0)         # False
bool("False")   # True — непустая строка
all([])         # True
any([])         # False
```

`==` сравнивает значения, `is` — идентичность объектов. Для отсутствия значения — `x is None`. `if items:` проверяет непустоту обычного контейнера. Не используй `is` для сравнения чисел и строк по значению.

`and` и `or` возвращают один из операндов, а не обязательно `bool`: `'' or 'резерв'` даёт `'резерв'`. Поэтому `value or default` заменит не только `None`, но и `0`, `False`, пустую строку.

### Не меняй размер коллекции при её переборе

Для фильтрации списка создай новый список comprehension. Для удаления ключей из словаря перебирай отдельный список ключей или создай новый словарь. Удаление элементов на ходу из списка может пропускать элементы; изменение размера словаря при его переборе вызывает `RuntimeError`.

## 14. Служебные методы: почему len работает без .len()

Служебные методы пишутся с двойными подчёркиваниями. Обычно их вызывает сам Python через привычный синтаксис. Это не полный каталог; цель — увидеть связь между действием и механизмом.

| Синтаксис | Связанный метод |
|---|---|
| `len(obj)` | `__len__` |
| `str(obj)`, `print(obj)` | `__str__` (возможен переход к `__repr__`) |
| `repr(obj)` | `__repr__` |
| `obj[key]` | `__getitem__` |
| `obj[key] = value` | `__setitem__` |
| `del obj[key]` | `__delitem__` |
| `for x in obj`, `iter(obj)` | `__iter__` (есть запасные механизмы) |
| `next(iterator)` | `__next__` |
| `x in obj` | `__contains__` или перебор |
| `a == b` | `__eq__` с правилами выбора реализации |
| `a < b` | `__lt__` с правилами выбора реализации |
| `a + b` | `__add__`, при необходимости `__radd__` |
| `a += b` | `__iadd__`, если реализован; иначе запасной путь через сложение |
| `bool(obj)` | `__bool__`, иначе `__len__`, иначе истина |
| `hash(obj)` | `__hash__` |
| `obj(...)` | `__call__` |
| `with obj:` | `__enter__`, `__exit__` |

`__init__` инициализирует уже созданный экземпляр; непосредственно создание связано с `__new__`. В методе экземпляра `self` — имя параметра по соглашению. Вызов `obj.method(x)` автоматически передаёт объект первым аргументом.

2. `str`: split, join, strip, replace, startswith, lower; f-строки.
3. `dict`: get, items, keys, values, update, pop, setdefault; накопление и группировка.
4. `set`: add, discard, пересечение/объединение; проверка наличия.
5. `len`, sorted, sum, min, max, enumerate, zip, any, all, isinstance.
6. Разница «изменяет объект / возвращает новый», ссылки и копии.
7. Функции, аргументы, return, классы, исключения и отладка.

Редкие методы строк, байтовые буферы и числовые преобразования достаточно узнавать и находить через справку. Умение выбрать несколько подходящих инструментов важнее воспроизведения всего списка.

## 16. Как проверить метод в своей версии Python

```python
help(dict.setdefault)  # назначение и сигнатура

# Все публичные вызываемые атрибуты типа:
methods = [name for name in dir(str)
           if not name.startswith("_") and callable(getattr(str, name))]
print(methods)
```

`getattr(str, name)` получает атрибут по имени; `callable` проверяет возможность вызова. Версию интерпретатора можно посмотреть через `import sys; print(sys.version)`.

Справочные точки для проверки поведения и версий: [встроенные типы](https://docs.python.org/3.14/library/stdtypes.html), [встроенные функции](https://docs.python.org/3.14/library/functions.html), [сортировка](https://docs.python.org/3.14/howto/sorting.html), [новое в Python 3.14](https://docs.python.org/3.14/whatsnew/3.14.html). Примеры и объяснения в этой шпаргалке составлены для нашей подготовки; перечень публичных методов дополнительно сверен с Python 3.14.
