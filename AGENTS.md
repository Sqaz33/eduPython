- Перед продолжением подготовки прочитай `STUDY_PLAN.md`: там актуальный маршрут, разобранные темы, наблюдения по ответам и следующий шаг.

- README не создавать. Пользовательские примеры не перезаписывать и не добавлять в коммит другого изменения.
